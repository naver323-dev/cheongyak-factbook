## 4. 값 정의

- **최저당첨가점(커트라인)** = 공고·주택형별 당첨자 중 최저 가점. 0(미달·가점제 미적용)은 제외.
- **지역 우선** = 해당지역 값 우선, 없으면 기타지역.
- **경쟁률** = 1순위·해당지역(없으면 기타지역) 접수건수 ÷ 공급세대수.
- **평형 구간** = 전용면적 60㎡ 이하 / 60~85㎡ / 85~102㎡ / 102㎡ 초과.
- **최근 2년** = 데이터 최근 공고일 − 730일.

## 5. 자동화·검증

- 파이프라인: `fetch.py`(원본 4종, 인증키 불필요 경로) → `fetch_details.py`(포털 미수록 최근 공고 246건 단지명·소재지 보완, 캐시) → `build.py` → `check.py`.
- `check.py` 검사: 필수 파일, JSON 파싱, 페이지·사이트맵 일치, viewport/canonical/GA 태그, JSON-LD 유효성, 가점 순서(최저≤평균≤최고) 및 0~84 범위, 표본 0 지역, llms.txt 내부 링크, robots의 AI 크롤러 허용, 금지 문구.
- 단위 테스트 10종(지역 파싱·평형 구간·0 제외·집계·끝단 검증). CI에서 통과 확인.
- 원본 수집 실패 시 커밋된 스냅샷으로 빌드하는 방어 코드 포함.
